向日葵主机上下线监控工具使用说明
================================

【文件说明】
- sunlogin_monitor.py    : 监控主脚本
- config.ini             : 配置文件
- SunloginMonitor.exe    : 打包好的可执行程序（无需 Python 环境）
- last_notify_id.txt     : 记录文件（自动生成，勿删）
- README.md              : 项目说明

【使用步骤（exe 版）】
1. 将 SunloginMonitor.exe 和 config.ini 放同一目录
2. 编辑 config.ini，填入你的 PushPlus Token
3. 双击 SunloginMonitor.exe 运行
4. 当检测到向日葵主机上下线时，会自动推送微信通知

【配置说明】
config.ini 格式：

[通知设置]
Token = [REDACTED:sha256:45bbc757edf0]
CheckInterval = 5

[数据库设置]
DBPath = C:\Users\{用户名}\AppData\Local\Microsoft\Windows\Notifications\wpndatabase.db
HandlerId = 90

注意：DBPath 中的 {用户名} 要改成你实际的 Windows 用户名。

【如何获取 PushPlus Token】
1. 访问 https://www.pushplus.plus/ 微信扫码登录
2. 首页复制你的 Token（一对一发送）
3. 完成实名认证（必须！未实名会报 905 错误）：
   https://verify.pushplus.plus

【工作原理】
- 监控 Windows 通知数据库（wpndatabase.db）中的向日葵通知
- 解析 Toast 通知内容（主机在线/下线）
- 翻译为英文（如"Device offline"）后通过 PushPlus 发送到微信

【注意事项】
- 推送服务已从 Server酱（已收费）迁移到 PushPlus（免费）
- v1.3 起 config.ini 使用 Token 字段，旧版 SendKey 不再支持
- 程序运行时不要关闭命令行窗口
- 如需开机自启动，将 exe 快捷方式放入 shell:startup 启动文件夹

【Python 源码运行（可选）】
需安装依赖：pip install requests
运行：python sunlogin_monitor.py
